# Troubleshooting

Use this section when something is not working as expected.

## How to troubleshoot effectively

1. Reproduce the issue with the smallest possible test case.
2. Check configuration and environment assumptions.
3. Review known issues and plugin-specific guidance.
4. Collect logs and execution evidence before escalating.

## Known issue pages

- [General troubleshooting](../troubleshooting.md)
- [Plugin troubleshooting](../plugins/pluginTroubleshooting.md)

## Before raising support requests

Include the INGenious version, platform details, relevant logs, and a minimal reproducible scenario.
